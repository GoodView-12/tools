文档

StudyMate 使用说明：题目格式、导入导出、答题流程、错题本等。

一、快速上手

  1. 准备题目：按下方 JSON 格式整理题目，保存为 .json 文件；或在「题库」页用编辑工作台手动创建。
  2. 导入题库：进入「题库」页，点击「选择 JSON 文件」→ 选中文件 → 点「导入」。
  3. 开始练习：进入「练习」页，点击题型卡片（挖空 / 单词 / 单选）→ 选择一套题目 → 开始答题。
  4. 查看错题：答错的题会自动收进「错题本」，可查看、移除，或一键转为新题库做专项练习。
  5. 查看统计：「统计」页记录每次练习的题型、套题、正确数和正确率。

二、JSON 题目格式

一个 JSON 文件代表一套题，包含两部分：

  • information：元信息（套题名称、题型、标签、作者）
  • quetions：题目集合，键为题目编号（如 "1"、"2"），值为该题内容

information 字段说明：

  • title（必填）：套题名称，展示在题库和选择套题时
  • type（必填）：题型，只能是 word / choice / blank 之一
  • tag（可选）：字符串数组，科目、年级、题型等标签
  • auther（可选）：署名，便于区分来源（拼写沿用项目约定）

完整骨架示例：

{
  "information": {
    "title": "题目套名称",
    "type": "word | choice | blank",
    "tag": ["标签1", "标签2"],
    "auther": "作者署名"
  },
  "quetions": {
    "1": { /* 第 1 题内容，字段随题型变化 */ },
    "2": { /* 第 2 题内容 */ }
  }
}

注意：题目集合的键名是 quetions（沿用项目既有拼写），不是 questions。导入时会按此字段读取。

三、三种题型的字段

1. 单词卡片（type: "word"）

练习时显示中文，用户填写英文，检查对错（忽略大小写和首尾空格）。每题两个字段：

  • word：中文释义，作为题干展示
  • ranslation：英文单词或短语，作为标准答案
{
  "information": {
    "title": "英语七上单词集合",
    "type": "word",
    "tag": ["英语", "单词"],
    "auther": "小明"
  },
  "quetions": {
    "1": { "word": "苹果", "ranslation": "apple" },
    "2": { "word": "香蕉", "ranslation": "banana" }
  }
}

2. 单选题（type: "choice"）

练习时展示题干和四个选项，选择后提交判断对错。每题三个字段：

  • quetion：题干文字
  • Option：四个选项的字符串数组，顺序对应 A / B / C / D
  • answer：正确选项的索引，从 0 开始（"0" = A，"1" = B，以此类推），字符串或数字均可
{
  "information": {
    "title": "历史选择题练习",
    "type": "choice",
    "tag": ["历史", "选择题"],
    "auther": "小红"
  },
  "quetions": {
    "1": {
      "quetion": "辛亥革命爆发于哪一年？",
      "Option": ["1911年", "1912年", "1919年", "1921年"],
      "answer": "0"
    }
  }
}

3. 知识语句挖空（type: "blank"）

练习时题干中的空位变成输入框，用户填写后检查。每题两个字段：

  • quetion：题干，用连续两个及以上下划线 ____ 表示空位
  • answer：标准答案，与用户输入完全一致（去除首尾空格）才算对
{
  "information": {
    "title": "近代史知识点挖空",
    "type": "blank",
    "tag": ["历史", "挖空"],
    "auther": "小刚"
  },
  "quetions": {
    "1": {
      "quetion": "辛亥革命是一场____性质的革命。",
      "answer": "资产阶级民主"
    }
  }
}

提示：一道题里如果有多个 ____，当前版本会把它们都替换成输入框，但只按一个答案判断。建议一题只挖一个空。

四、导入与校验规则

  • 在「题库」页选择 .json 文件后，点击「导入」才真正写入题库。
  • 导入时会校验：必须有 information、information.type、quetions 三个字段。
  • information.type 必须是 word / choice / blank 之一，否则拒绝导入。
  • 校验通过后，题目存入浏览器 localStorage，刷新页面不丢失。
  • 同一文件可以重复导入，会生成多套独立题目（每套有独立 id）。

五、导出与分享

  • 题库页每套题有「导出 JSON」按钮，点击下载该套题的 .json 文件。
  • 导出格式与导入格式完全一致，可以直接发给别人，对方在「题库」页导入即可。
  • 题库列表和「查看详情」的预览不显示答案，答案只在答题判断时使用，避免预览时泄露。

六、编辑工作台

  • 在「题库」页点「＋ 新建题目套」进入工作台。
  • 填写标题（必填）、题型、标签（逗号分隔）、作者。
  • 切换题型时，下方题目表单会自动切换字段：单词 → 中文/英文；单选 → 题干 + 4 选项 + 正确项；挖空 → 题干 + 答案。
  • 点「＋ 添加一道题」增加题目，每题可单独删除。
  • 点「保存到题库」会校验每道题是否填完整，通过后写入题库。
  • 已有套题可在题库页点「编辑」再次打开工作台修改，保存时按 id 更新原套题。

七、答题流程与判分

  • 答题界面顶部有进度条、「已答 / 总数」、「正确数」；底部有题目导航点，可点击跳转任意题。
  • 挖空题：用户输入答案 → 点「检查」→ 正确变绿、错误变红并显示正确答案。答错时保留用户的输入，方便对照。
  • 单词卡片：显示中文 → 用户填写英文 → 点「检查」。判分忽略大小写和首尾空格。
  • 单选题：用户点击选项高亮 → 点「提交答案」→ 正确项标绿、错选项标红。
  • 点「下一题」或导航点切换题目；最后一道题点「下一题」进入结果页。
  • 结果页显示正确率、正确数、错误/未答数、总题数，可「重新开始」「选择其他套题」「查看统计」，有错题时还可「去错题本」。

八、错题本

  • 答题时答错的题（挖空 / 单词 / 单选）会自动收进错题本。
  • 去重规则：按题目内容生成指纹，同一道题反复错只累加「错误次数」，不会重复收录。
  • 错题本按题型分组展示，每题显示题目、正确答案、错误次数、最近错误时间、来源套题。
  • 每题可单独「移除」；顶部「清空错题本」可全部删除。
  • 每个题型分组有「转为题库」按钮：把该题型所有错题打包成一套新题目写入题库，命名格式为「XX 错题专项（X月X日）」，标签自动带「错题专项」。转换后这些题会从错题本移除。
  • 侧边栏「错题本」入口带红色数字角标，实时显示错题总数。

九、统计

  • 每次完成一套练习，会记录一条：时间、题型、套题名、正确数、总题数。
  • 统计页顶部展示：练习次数、累计题数、平均正确率、当前错题数。
  • 「最近练习记录」展示最近 10 条；「按题型汇总」按挖空 / 单词 / 单选分别统计练习次数、正确数和正确率。
  • 练习记录最多保留 200 条，超出后自动丢弃最早的。

十、数据存储与隐私

  • 所有数据（题库、练习记录、错题本）都保存在浏览器 localStorage，不上传任何服务器。
  • 换设备、换浏览器、清除浏览器数据后，数据不会自动同步或恢复。
  • 想把题库分享给别人，请用「导出 JSON」→ 对方导入的方式显式传递。
  • 同一台电脑同一浏览器用 file:// 打开时，不同 HTML 文件可能共享 localStorage；部署到服务器或 localhost 时按域名隔离，更干净。

十一、常见问题

  • 导入报「JSON 解析失败」：检查文件是否是合法 JSON（引号、逗号、括号是否配对），可用在线 JSON 校验工具检查。
  • 导入报「缺少字段」：确认有 information、information.type、quetions 三个字段。
  • 导入报「type 必须是…」：information.type 只能填 word / choice / blank，注意大小写。
  • 挖空题检查总是错：答案比较是严格匹配（去除首尾空格），标点、空格、全半角都要一致。
  • 单词检查总是错：单词比较忽略大小写，但拼写必须一致，注意空格和连字符。
  • 单选题总判错：answer 是从 0 开始的索引，不是选项文字。A 填 "0"，B 填 "1"。
  • 刷新后数据没了：可能清除了浏览器数据，或用无痕模式打开。localStorage 只存在于当前浏览器。

十二、用 AI 生成题目 JSON

如果不想手动写 JSON，可以把下面这段提示词复制给 AI（如 ChatGPT、Claude、DeepSeek 等），在留空处填上自己的知识点和要求，让 AI 按 StudyMate 的格式输出一套题目。提示词已约束 AI 只能基于用户提供的材料出题，不得凭空编造。

使用方法：

  1. 点右下角「复制提示词」。
  2. 把提示词粘贴到 AI 对话框。
  3. 把「【在此填写知识点 / 教材范围 / 题目要求】」整段替换成实际内容，例如课文原文、单词表、考点列表、题目数量、难度等。
  4. 发送后，把 AI 返回的 JSON 保存为 .json 文件，在「题库」页导入。
你是一个严格遵守格式的题目生成助手。请根据我提供的知识点材料，生成一套可直接导入 StudyMate 的 JSON 题目。

【硬性要求】
1. 只输出 JSON，不要输出任何解释、Markdown 代码块标记（如 ```json）、前后缀文字。
2. JSON 必须能被 JSON.parse 直接解析，不能有注释、不能有尾随逗号。
3. 只能基于我提供的材料出题，不得编造材料中没有的事实、数据、人名、年份。材料未覆盖的内容不要出题。
4. 题目数量、难度、题型以我的要求为准；如果我没指定，默认出 5 道题，难度中等。
5. 题目内容使用简体中文；英文单词题除外。

【JSON 结构】
{
  "information": {
    "title": "套题名称",
    "type": "word 或 choice 或 blank",
    "tag": ["标签1", "标签2"],
    "auther": "AI 生成"
  },
  "quetions": {
    "1": { },
    "2": { }
  }
}

【字段规则】
- information.title：套题名称，简洁概括内容。
- information.type：整套题只能是一种题型，取值为 "word" / "choice" / "blank" 之一。
- information.tag：字符串数组，放科目、年级、章节等标签。
- information.auther：固定填 "AI 生成"。
- quetions：对象，键为 "1"、"2"、"3"… 的字符串编号，值为题目对象。

【三种题型的题目字段】
1. type = "word"（单词卡片）：
   { "word": "中文释义", "ranslation": "英文单词或短语" }
   注意字段名是 ranslation（项目约定拼写），不要改成 translation。

2. type = "choice"（单选题）：
   {
     "quetion": "题干文字",
     "Option": ["选项A", "选项B", "选项C", "选项D"],
     "answer": "正确选项的索引，从 0 开始，字符串形式"
   }
   - Option 必须是 4 个字符串。
   - answer 是 "0" / "1" / "2" / "3"，对应 A / B / C / D。
   - 四个选项要互斥，只有一个正确，干扰项要合理但明确错误。

3. type = "blank"（知识挖空）：
   {
     "quetion": "题干，用连续两个及以上下划线 ____ 表示一个空位",
     "answer": "标准答案"
   }
   - 一道题只挖一个空，避免多空导致判分歧义。
   - 答案与题干中的空位一一对应，答案要唯一、明确、可在材料中直接找到依据。

【我提供的材料与要求】
【在此填写知识点 / 教材范围 / 题目要求】
例如：
- 材料：辛亥革命发生于1911年，推翻了清朝统治，结束了中国两千多年的君主专制制度，建立了中华民国。
- 题型：choice
- 数量：3 道
- 难度：中等
- 要求：考查时间、历史意义、政治制度变化

【输出检查】
输出前自检：
- 是否为合法 JSON（无注释、无尾随逗号、引号配对）。
- information.type 是否只有一种题型。
- 每道题字段是否与对应题型完全一致。
- 单选题 answer 是否为 "0"~"3" 的字符串。
- 挖空题是否只有一个 ____ 且 answer 与之对应。
- 是否只用了材料中的信息，没有编造。

确认无误后，直接输出 JSON。

关于 StudyMate

StudyMate 是一个面向个人学习者的轻量复习助手，帮助你用三种方式反复巩固知识：

📝 知识语句挖空：把定义、事件、概念中的关键词挖空，练习回忆与填写。

🃏 英语单词短语填写：看中文填写英文，检查对错，适合单词和术语。

✅ 单选题问答：四选一自测，立即反馈对错。

📕 错题本：自动收录错题，可一键转为新题库做专项练习。

所有题目由用户以 JSON 文件导入或用编辑工作台自主制作，数据仅保存在浏览器本地（localStorage），不上传任何服务器。支持把套题导出为 JSON 文件分享给别人。项目使用原生 HTML / CSS / JavaScript 构建。
